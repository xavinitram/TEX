// Pixelate — mosaic / block effect
//
// Quantizes the pixel index to a grid, then samples the
// image at each block's top-left pixel. Every pixel in
// the same block gets the same color, creating a mosaic.

f$block_size = 16.0;   // block size in pixels

// Snap the pixel index to its block's first pixel, then convert to UV
// (u runs 0..1 over iw-1 steps, so divide by iw-1, as u itself does)
float su = floor(float(ix) / $block_size) * $block_size / max(iw - 1.0, 1.0);
float sv = floor(float(iy) / $block_size) * $block_size / max(ih - 1.0, 1.0);

// Sample the image at the snapped position
@OUT = sample(@image, su, sv);
